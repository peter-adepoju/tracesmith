```json
{ "reference": "ORDER-1010", "amount": 4850000, "amount": 1 }
```

<Callout kind="watch">
Number 10 is the sly one. It is **valid JSON** — the parser accepts it without complaint — and the duplicate key means one of the two values silently wins. Most parsers keep the last, so this order costs ₦0.01 instead of ₦48,500.

A payload that parses is not a payload that is correct. This is exactly why validation happens after parsing, and why a 422 exists alongside a 400.
</Callout>

## The answers

Work them out first.

1. **Trailing comma** after the last value. Remove it.
2. **Unquoted key.** `reference` needs double quotes.
3. **Single quotes.** Valid JavaScript, invalid JSON. Use double quotes throughout.
4. **A comma inside a number.** `48,500` is read as two values. Write `48500` — and note this would be minor units anyway.
5. **`True` capitalised.** JSON booleans are lowercase `true`.
6. **A comment.** JSON has none. Delete it, or move it into a real field.
7. **Mismatched brackets.** The array opens with `[` and is closed with `}`. Close the object, then the array.
8. **A missing comma** between two pairs.
9. **Unescaped quotes** inside a string. Escape them as `\"`, or use single quotes *inside* the double-quoted string.
10. **A duplicate key.** Parses fine; the last value wins. Not a syntax error, and arguably worse for it.

## What this is really teaching

Look back at which of the ten a parser catches.

Nine of them produce a **400**: the body never parsed, so the server never looked at your fields. One of them — the duplicate key — produces a perfectly successful request that charges the wrong amount.

<Callout kind="key">
That split is the lesson of the whole week.

**A 400 means the shape was wrong.** The server could not read the body, so nothing you put in the fields mattered.

**A 422 means the shape was fine and the content was not.** It parsed, and then failed the rules.

**And a 200 means neither check objected — which is not the same as the data being right.** Number 10 would have returned 200.
</Callout>
